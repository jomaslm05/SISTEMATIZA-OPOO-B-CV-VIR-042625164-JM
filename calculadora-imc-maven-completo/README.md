# Calculadora IMC

Projeto Java orientado a objetos para cálculo de IMC de pessoas e atletas.

## Pré-requisitos
- Java 17+
- Maven 3.8+

## Compilar
```bash
mvn package
```

## Executar
```bash
java -cp target/classes Main
```

## Funcionalidades
- Cadastro de Pessoa
- Cadastro de Atleta
- Cálculo de IMC
- Histórico de cálculos
- Recursão
- Exceções personalizadas
- Herança, Interface, Polimorfismo e Composição
